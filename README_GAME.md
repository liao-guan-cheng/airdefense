# 防空避難守護者：陀螺對決挑戰賽

一款結合「戰鬥陀螺」元素的防空避難宣導網頁遊戲，透過問答挑戰和陀螺對決的方式，向玩家宣導防空避難的重要知識。

## 快速開始

### 線上遊玩
直接訪問部署的網站URL即可開始遊戲，無需任何安裝或配置。

### 本地開發

```bash
# 安裝依賴
pnpm install

# 啟動開發伺服器
pnpm dev

# 訪問 http://localhost:3000
```

## 遊戲特色

### 🎮 遊戲玩法
- **開場動畫**：警察NPC邀請玩家接受挑戰
- **三大主題**：防空避難觀念、處所查詢、避難包宣導
- **問答系統**：21道精心設計的防空知識問題
- **陀螺組裝**：集齊零件組裝防空避難守護者
- **最終對決**：與空襲威脅者進行陀螺對戰

### 🎨 視覺設計
- 高質量的生成式圖像素材
- 流暢的Framer Motion動畫
- 響應式設計支持所有設備
- 深色主題配合警報視覺效果

### 📚 教育內容
- 防空警報識別與避難原則
- 警政服務APP使用指南
- 緊急避難包準備清單
- 每題都包含詳細解釋說明

## 技術棧

| 層級 | 技術 |
|------|------|
| 框架 | React 19 + TypeScript |
| 樣式 | Tailwind CSS 4 |
| 動畫 | Framer Motion |
| UI組件 | shadcn/ui |
| 狀態管理 | React Context |
| 路由 | Wouter |

各個場景組件中的文本都可以直接修改。
